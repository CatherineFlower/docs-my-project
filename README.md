# Smart Study Planner — системный анализ и проектная документация

## О проекте

**Smart Study Planner** — это веб-сервис интеллектуального планирования учебной деятельности студентов. Система предназначена для централизованного управления учебными задачами, дедлайнами и календарными событиями с автоматическим формированием сбалансированного учебного плана.

Проектная документация была разработана в рамках курса **«Системный анализ» от Т-Академии** и представляет собой полный набор аналитических артефактов, необходимых для проектирования и дальнейшей разработки информационной системы.

Документация оформлена в формате **Docs as Code** с использованием **Docusaurus** и опубликована через **GitHub Pages**.

---

## Цель проекта

Основная цель проекта — решить проблему хаотичного управления учебной нагрузкой студентов.

На практике студенты используют несколько разрозненных источников информации:

* LMS-системы;
* личные заметки;
* календари;
* чаты и мессенджеры.

Из-за этого:

* задачи теряются;
* дедлайны отслеживаются неэффективно;
* нагрузка распределяется неравномерно;
* отсутствует централизованное планирование.

Smart Study Planner объединяет учебные данные в единую систему и автоматически формирует оптимизированный недельный план с учетом приоритетов, дедлайнов и загруженности пользователя.
