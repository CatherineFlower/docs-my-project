# **Задание 1. Wireframes и пользовательские сценарии**

## **Ссылка на макеты**

Wireframes экранов и пользовательские переходы размещены на доске:
[https://unidraw.io/app/board/7672fbbf4a6a31950314](https://unidraw.io/app/board/7672fbbf4a6a31950314)

Для отрисовки экранов были использованы платформы: Miro и Figma

## **1. Общий сценарий работы системы**

Основной пользовательский сценарий:

1. Пользователь проходит авторизацию.

2. Попадает на главный экран.

3. Просматривает задачи или календарь.

4. Формирует недельный план.

5. При необходимости редактирует план.

6. Сохраняет результат.

## **2. Список экранов и их логика**

### **2.1 Экран входа**

**Route:** `/login`

Назначение — авторизация пользователя.

Элементы:

- Email

- Пароль

- Кнопка «Войти»

- Ссылка на регистрацию

Переходы:

- Успешный вход → `/home`

- Переход к регистрации → `/register`

Источник данных:

- POST `/auth/login`

### **2.2 Экран регистрации**

**Route:** `/register`

Назначение — создание аккаунта.

Элементы:

- Email

- Пароль

- Подтверждение пароля

- Кнопка «Зарегистрироваться»

Переходы:

- Успешная регистрация → `/home`

- Назад → `/login`

Источник данных:

- POST `/auth/register`

### **2.3 Главный экран**

**Route:** `/home`

Назначение — центральная точка входа.

Элементы:

- Приветствие пользователя

- Список задач на сегодня

- Быстрые действия:

    - Сформировать план

    - Календарь

    - Задачи

- Блок текущего плана

Переходы:

- → `/tasks`

- → `/calendar`

- → `/generate-plan`

- → `/weekly-plan`

Источник данных:

- GET `/users/me`

- GET `/tasks?date=today`

- GET `/plans/weekly`

### **2.4 Экран задач**

**Route:** `/tasks`

Назначение — просмотр задач.

Элементы:

- Список задач

- Фильтры

- Приоритеты

Переходы:

- → `/generate-plan`

Источник данных:

- GET `/tasks`

### **2.5 Экран календаря**

**Route:** `/calendar`

Назначение — просмотр событий.

Элементы:

- Календарь

- Список событий

Переходы:

- → `/generate-plan`

Источник данных:

- GET `/calendar/events`

### **2.6 Экран генерации плана**

**Route:** `/generate-plan`

Назначение — выбор задач и событий для формирования плана.

Элементы:

- Список задач

- Список событий

- Кнопка «Сгенерировать»

Переходы:

- → `/weekly-plan`

Источник данных:

- GET `/tasks`

- GET `/calendar/events`

- POST `/plans/generate`

### **2.7 Экран недельного плана**

**Route:** `/weekly-plan`

Назначение — просмотр результата генерации.

Элементы:

- Дни недели

- Задачи по дням

- Кнопки:

    - Сохранить

    - Редактировать

Переходы:

- → `/edit-plan`

Источник данных:

- GET `/plans/weekly`

### **2.8 Экран редактирования плана**

**Route:** `/edit-plan`

Назначение — ручное изменение плана.

Элементы:

- Перетаскивание задач

- Добавление / удаление задач

- Кнопка «Сохранить»

Переходы:

- → `/weekly-plan`

Источник данных:

- GET `/plans/weekly`

- PUT `/plans/weekly`

### **2.9 Экран профиля**

**Route:** `/profile`

Назначение — управление пользователем.

Элементы:

- Имя

- Email

- Настройки

Источник данных:

- GET `/users/profile`

- PATCH `/users/profile`

- POST `/auth/logout`
