## **Задание 1. Платформизация курсового проекта**

### **1. Стратегия платформизации**

Приложение **Smart Study Planner** может быть реализовано как платформа, предоставляющая сервис интеллектуального планирования учебной нагрузки.

Проект выступает как надстройка над существующими образовательными системами и решает задачу персонального распределения задач и времени.

### **2. Целевая аудитория**

Платформа может быть продана следующим типам организаций:

- университеты

- онлайн-школы

- EdTech-платформы

- корпоративные обучающие центры

### **3. Ценность продукта**

- не заменяет существующие LMS-системы

- дополняет их

- преобразует учебные задачи в персональный план пользователя

- снижает нагрузку на студентов за счёт автоматического распределения задач

### **4. Модель бизнеса**

**B2B2C**

```Plain Text
Платформа → образовательная организация → пользователи (студенты)
```

**Обоснование:**

- платит организация

- конечный пользователь - студент

- легко масштабируется на большое количество пользователей

### **5. Стратегия монетизации**

Основная модель - **подписка**

Возможные варианты:

- фиксированная стоимость для организации

- оплата за активного пользователя

**Обоснование:**

- предсказуемая выручка

- удобство масштабирования

- стандартная модель для SaaS-продуктов

### **6. Почему проект платформизуем**

Проект можно реализовать как платформу, потому что:

- используется универсальная предметная область (задачи, календарь, планирование)

- не зависит от конкретной организации

- может интегрироваться с внешними системами

- архитектура допускает расширение через API

- основная ценность - алгоритм планирования и логика распределения задач

### 7. Дополнение
