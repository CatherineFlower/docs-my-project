# Smart Study Planner

Smart Study Planner — веб-сервис интеллектуального планирования учебной деятельности студентов. Система централизует учебные задачи, дедлайны и календарные события, после чего формирует сбалансированный недельный план.

Документация оформлена в формате Docs as Code для Docusaurus и GitHub Pages. Внутри собраны артефакты предыдущих работ: требования, UX-сценарии, API, асинхронное взаимодействие, BPMN/DMN, UML-диаграммы, ERD, модель хранения данных, алгоритм планирования и эксплуатационные инструкции.

## Ключевая проблема

Студенты часто хранят учебные задачи в разных источниках: LMS, личных заметках, календарях и чатах. Из-за этого дедлайны отслеживаются хаотично, приоритеты определяются интуитивно, а нагрузка распределяется неравномерно. Smart Study Planner решает эту проблему через централизованное хранение задач, автоматическую приоритизацию и недельное планирование.

## Основные возможности

- регистрация и авторизация пользователя;
- создание и просмотр учебных задач;
- импорт дедлайнов из LMS как перспективная интеграция;
- получение календарных событий;
- автоматическое определение приоритета;
- генерация недельного плана;
- проверка перегруза по дням;
- ручная корректировка и сохранение плана;
- хранение истории действий и аналитики.
