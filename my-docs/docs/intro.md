# Smart Study Planner

Smart Study Planner — умный планировщик учебных задач для студентов.

Данная документация оформлена в подходе docs as code. Материалы хранятся в Markdown, версионируются через GitHub и публикуются через GitHub Pages.

## Состав документации

Документация сформирована на основе материалов проекта, выгруженных из Buildin.AI.

В составе документации представлены:

- концепция системы;
- требования;
- архитектурные материалы;
- API-описания;
- диаграммы;
- алгоритмы;
- шаблоны технических артефактов.
