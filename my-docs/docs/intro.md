# Smart Study Planner

**Smart Study Planner** — веб-сервис интеллектуального планирования учебной деятельности студентов. Система помогает собирать учебные задачи в одном месте, рассчитывать приоритеты, учитывать дедлайны, календарные события и формировать сбалансированный недельный план.

Документация собрана по подходу **Docs as Code**: все материалы хранятся в репозитории рядом с исходными файлами, оформлены в Markdown и публикуются через Docusaurus на GitHub Pages.

## Назначение системы

Студенты часто ведут дедлайны в разных местах: LMS, календарях, личных заметках и мессенджерах. Из-за этого задачи выполняются в последний момент, нагрузка распределяется неравномерно, а приоритеты выбираются интуитивно. Smart Study Planner решает эту проблему за счёт централизованного списка задач, автоматической приоритизации и генерации недельного плана.

## Ключевые функции MVP

В MVP входят регистрация и авторизация, CRUD задач, автоматическая приоритизация, генерация недельного плана, работа с календарными событиями, базовая аналитика и внутренние уведомления.
