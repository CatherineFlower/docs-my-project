# Smart Study Planner — Техническая документация

## О проекте

**Smart Study Planner** — информационная система интеллектуального планирования учебной деятельности студентов. Система анализирует дедлайны, сложность задач и доступное время пользователя, автоматически формируя сбалансированный план на неделю.

## Назначение документации

Данная документация описывает архитектуру, функциональные требования, API, алгоритмы и другие технические аспекты системы Smart Study Planner. Документация предназначена для:

- разработчиков проекта;
- тестировщиков;
- технических писателей;
- заинтересованных стейкхолдеров.

## Краткое описание системы

### Проблема

Студенты сталкиваются с разрывом между необходимостью контролировать учебную нагрузку и фактическим хаотичным управлением задачами:

- дедлайны распределены по разным источникам;
- приоритеты определяются интуитивно;
- задачи выполняются в последний момент;
- нагрузка распределяется неравномерно.

### Решение

Smart Study Planner предоставляет:

- централизованное хранение задач;
- автоматическую приоритизацию на основе DMN-моделей;
- равномерное распределение нагрузки;
- снижение просрочек и стресса.

### Ключевые функции

1. **CRUD задач** — создание, чтение, обновление, удаление учебных задач.
2. **Автоматическая генерация плана** — формирование недельного плана на основе дедлайнов и сложности.
3. **Приоритизация** — расчёт приоритета задач по срочности, трудоемкости и наличию дедлайна.
4. **Аналитика загрузки** — визуализация нагрузки по дням недели.
5. **Интеграции** — возможность подключения к LMS вуза и календарю.

## Технологический стек

- **Frontend:** React (веб-интерфейс)
- **Backend:** REST API
- **База данных:** реляционная БД (PostgreSQL)
- **Асинхронное взаимодействие:** WebSocket
- **Моделирование процессов:** BPMN, DMN
