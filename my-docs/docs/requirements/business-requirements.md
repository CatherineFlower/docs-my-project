# Бизнес-требования

## Описание проблемы

Студенты сталкиваются с разрывом между необходимостью контролировать учебную нагрузку и фактическим хаотичным управлением задачами.

### Текущее состояние

- дедлайны распределены по разным источникам;
- приоритеты определяются интуитивно;
- задачи выполняются в последний момент;
- нагрузка распределяется неравномерно.

### Желаемое состояние

- централизованное хранение задач;
- автоматическая приоритизация;
- равномерное распределение нагрузки;
- снижение просрочек и стресса.

## Цели проекта

| Цель | Описание | Метрика успеха |
|------|----------|----------------|
| Централизация задач | Объединение всех учебных задач в одном месте | 100% задач пользователя в системе |
| Автоматизация планирования | Снижение ручного труда при планировании | Время на планирование ≤ 5 мин/неделю |
| Снижение просрочек | Уменьшение количества просроченных задач | Снижение на 25% за 3 месяца |
| Улучшение wellbeing | Снижение стресса от учебной нагрузки | CSAT ≥ 4,3 |

## Заинтересованные стороны

| Стейкхолдер | Интересы | Влияние |
|-------------|----------|---------|
| Студенты | Удобство, экономия времени | Высокое |
| Владелец продукта | Рост аудитории, монетизация | Высокое |
| Команда разработки | Техническое качество | Среднее |
| Регуляторы (152-ФЗ) | Защита персональных данных | Высокое |
