# Нефункциональные требования

## Производительность

| ID | Требование | Приоритет | Обоснование |
|----|------------|-----------|-------------|
| NFR-01 | Время отклика ≤ 1 сек для 95% запросов | Must Have | Влияет на удержание пользователей |
| NFR-02 | Поддержка 50 000 одновременных пользователей | Should Have | Масштабируемость системы |

## Доступность

| ID | Требование | Приоритет | Обоснование |
|----|------------|-----------|-------------|
| NFR-03 | SLA ≥ 99% | Must Have | Критично для доверия пользователей |

## Безопасность

| ID | Требование | Приоритет | Обоснование |
|----|------------|-----------|-------------|
| NFR-04 | Соответствие 152-ФЗ | Must Have | Юридическое требование |
| NFR-05 | TLS 1.2+ для всех соединений | Must Have | Защита данных при передаче |

## Надёжность

| ID | Требование | Приоритет | Обоснование |
|----|------------|-----------|-------------|
| NFR-06 | Ежедневное резервное копирование | Should Have | Восстановление после сбоев |

## Обоснование непокрытых категорий

Не покрыты следующие категории:

| Категория | Причина | Риск |
|-----------|---------|------|
| Локализация | MVP запускается только в РФ | Низкий |
| Портируемость | Только веб-версия | Низкий |
| Совместимость с LMS | Вне границ MVP | Низкий |
