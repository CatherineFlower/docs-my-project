# Концепция Smart Study Planner

## Описание проблемы

Студенты сталкиваются с разрывом между необходимостью контролировать учебную нагрузку и фактическим хаотичным управлением задачами.

### Текущее состояние

- дедлайны распределены по разным источникам;
- приоритеты определяются интуитивно;
- задачи выполняются в последний момент;
- нагрузка распределяется неравномерно.

### Желаемое состояние

- централизованное хранение задач;
- автоматическая приоритизация;
- равномерное распределение нагрузки;
- снижение просрочек и стресса.

## Текущие альтернативы

| Альтернатива | Недостатки |
|--------------|------------|
| Заметки и бумажные списки | отсутствует учебная логика, нет расчёта от дедлайна назад |
| Trello / Notion | нет автоматической пересборки плана, нет анализа перегрузки |
| Календарь | не предназначен для управления задачами, нет приоритизации |
| Личная память | высокий риск забыть задачи, отсутствие системности |

## Целевая аудитория

### Сегмент 1: Студенты 1-2 курса

**Поведение:**
- отсутствует привычка планирования;
- задачи добавляются в последний момент.

**Взаимодействие с системой:**
- используют автоматическую приоритизацию;
- опираются на напоминания;
- редко настраивают правила вручную.

### Сегмент 2: Студенты 3-4 курса

**Поведение:**
- работают с крупными проектами;
- декомпозируют задачи;
- совмещают учебу и работу.

**Взаимодействие с системой:**
- используют недельное планирование;
- активно применяют аналитику загрузки;
- создают крупные события (экзамен, диплом).

### Сегмент 3: Стажёры и работающие студенты

**Поведение:**
- ограничены по времени;
- имеют фиксированный график работы.

**Взаимодействие с системой:**
- задают временные ограничения;
- часто используют пересборку плана;
- вручную корректируют приоритет.

## Описание продукта

Smart Study Planner — веб-сервис, который анализирует дедлайны, сложность задач и доступное время пользователя, автоматически формируя сбалансированный план на неделю.

### Ключевые функции (User Stories)

| ID | User Story | Приоритет |
|----|------------|-----------|
| US-01 | Как студент, я хочу создать задачу с дедлайном и временем выполнения, чтобы учитывать её в планировании | Must Have |
| US-02 | Как студент, я хочу автоматически получить план на неделю, чтобы распределить нагрузку | Must Have |
| US-03 | Как студент, я хочу видеть риск просрочки, чтобы вовремя скорректировать план | Must Have |
| US-04 | Как студент, я хочу разбить крупную задачу на этапы, чтобы контролировать прогресс | Should Have |
| US-05 | Как студент, я хочу видеть аналитику загрузки, чтобы понимать перегруз | Should Have |

### KPI продукта

- Количество регистраций
- MAU / WAU
- Retention D7 / D30
- Доля выполненных задач до дедлайна
- Конверсия в подписку
- LTV
- CSAT ≥ 4,3

## Границы проекта (MVP)

### Входит в MVP

- Регистрация и авторизация
- CRUD задач
- Автоматическая приоритизация
- Генерация недельного плана
- События (экзамен, проект)
- Базовая аналитика
- Внутренние уведомления

### Не входит в MVP

- Мобильное приложение
- Интеграции с LMS
- Командная работа
- AI-оценка времени

## Версии продукта и план развития

### Версия 1 (MVP)

Базовые задачи + планирование + события + аналитика.

### Версия 2

- гибкая настройка приоритетов (правила);
- шаблоны задач по предметам;
- расширенные напоминания (email/telegram);
- улучшенная аналитика (причины просрочек, «узкие места»).

### Версия 3

- интеграции (календарь, расписание);
- командные проекты (общий список задач на команду);
- персонализация (учёт предпочтений по времени: утро/вечер).
