# Wireframes и пользовательские сценарии

## Общий сценарий

Пользователь проходит авторизацию, попадает на главный экран, просматривает задачи или календарь, формирует недельный план, при необходимости редактирует его и сохраняет результат.

## Экраны

### Экран входа

**Route:** `/login`  
**Назначение:** авторизация пользователя.  
**Источник данных:** `POST /auth/login`.

Элементы: email, пароль, кнопка «Войти», ссылка на регистрацию. После успешного входа пользователь переходит на `/home`, при выборе регистрации — на `/register`.

### Экран регистрации

**Route:** `/register`  
**Назначение:** создание аккаунта.  
**Источник данных:** `POST /auth/register`.

Элементы: email, пароль, подтверждение пароля, кнопка «Зарегистрироваться». После успешной регистрации пользователь переходит на `/home`.

### Главный экран

**Route:** `/home`  
**Назначение:** центральная точка входа в приложение.  
**Источники данных:** `GET /users/me`, `GET /tasks?date=today`, `GET /plans/weekly`.

Главный экран показывает приветствие, задачи на сегодня, быстрые действия и блок текущего плана.

### Экран задач

**Route:** `/tasks`  
**Назначение:** просмотр и фильтрация задач.  
**Источник данных:** `GET /tasks`.

Экран показывает список задач, фильтры и приоритеты. Из него можно перейти к генерации плана.

### Экран календаря

**Route:** `/calendar`  
**Назначение:** просмотр событий.  
**Источник данных:** `GET /calendar/events`.

Календарь используется для отображения занятости пользователя и передачи событий в алгоритм планирования.

### Экран генерации плана

**Route:** `/generate-plan`  
**Назначение:** выбор задач и событий для формирования плана.  
**Источники данных:** `GET /tasks`, `GET /calendar/events`, `POST /plans/generate`.

Пользователь выбирает задачи и события, после чего запускает генерацию недельного плана.

### Экран недельного плана

**Route:** `/weekly-plan`  
**Назначение:** просмотр результата генерации.  
**Источник данных:** `GET /plans/weekly`.

Экран показывает дни недели и задачи по дням. Пользователь может сохранить или отредактировать план.

### Экран редактирования плана

**Route:** `/edit-plan`  
**Назначение:** ручное изменение плана.  
**Источники данных:** `GET /plans/weekly`, `PUT /plans/weekly`.

Пользователь может переносить задачи между днями, добавлять и удалять задачи, а затем сохранять изменения.

### Экран профиля

**Route:** `/profile`  
**Назначение:** управление профилем и настройками.  
**Источники данных:** `GET /users/profile`, `PATCH /users/profile`, `POST /auth/logout`.
