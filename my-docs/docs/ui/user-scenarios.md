# Пользовательские сценарии

## Сценарий 1. Первый вход

1. Пользователь открывает приложение.
2. Переходит на экран регистрации.
3. Создаёт аккаунт.
4. Попадает на главный экран.
5. Видит пустой список задач и предложение добавить первую задачу.

## Сценарий 2. Работа с задачами

1. Пользователь открывает раздел задач.
2. Просматривает список учебных задач.
3. Добавляет новую задачу с дедлайном и оценкой времени.
4. Система сохраняет задачу и учитывает её при генерации плана.

## Сценарий 3. Генерация недельного плана

1. Пользователь открывает экран генерации плана.
2. Выбирает задачи и события календаря.
3. Нажимает кнопку «Сгенерировать».
4. Система формирует план и показывает результат.
5. Пользователь подтверждает или корректирует план.

## Сценарий 4. Ручное редактирование

1. Пользователь открывает недельный план.
2. Нажимает «Редактировать».
3. Переносит задачи между днями.
4. Сохраняет изменения.
5. Обновлённый план становится текущим.
