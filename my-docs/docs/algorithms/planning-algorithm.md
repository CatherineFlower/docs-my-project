# Алгоритм планирования

Алгоритм формирует недельный план на основе задач, дедлайнов, календарных событий и приоритетов.

## Входные данные

- список задач пользователя;
- дедлайны из LMS, если интеграция подключена;
- календарные события пользователя;
- оценка трудоёмкости задачи;
- приоритет задачи;
- доступные временные окна недели.

## Этапы алгоритма

1. Получить задачи пользователя.
2. Получить календарные события.
3. Импортировать дедлайны из LMS при наличии интеграции.
4. Объединить данные.
5. Проверить полноту параметров задач.
6. Определить приоритет каждой задачи через DMN.
7. Отсортировать задачи по приоритету, дедлайну и трудоёмкости.
8. Построить доступные временные слоты по дням недели.
9. Распределить задачи по слотам.
10. Проверить перегрузку по дням.
11. При необходимости пересобрать план.
12. Вернуть план пользователю для подтверждения.

## Правила сортировки

Сначала размещаются задачи с высоким приоритетом, затем задачи со средним и низким. Внутри одного приоритета раньше размещаются задачи с более близким дедлайном. Крупные задачи могут разбиваться на несколько блоков.

## Обработка перегруза

Если в один день попадает слишком много задач, система пытается перенести часть задач на соседние дни до дедлайна. Если перенос невозможен, пользователь получает предупреждение о риске перегрузки.

## Псевдокод

```text
input: tasks, calendarEvents, weekRange

availableSlots = buildSlots(weekRange, calendarEvents)
for task in tasks:
    task.priority = determinePriority(task)

sortedTasks = sortByPriorityDeadlineAndEffort(tasks)
plan = emptyPlan(weekRange)

for task in sortedTasks:
    slot = findBestAvailableSlot(task, availableSlots)
    if slot exists:
        placeTask(plan, task, slot)
    else:
        markAsRisk(task)

if hasOverload(plan):
    plan = rebalance(plan)

return plan
```
