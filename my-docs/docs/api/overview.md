# Обзор API

## Подход к проектированию

API построено в формате REST и соответствует **2 уровню зрелости Ричардсона**:

- используются ресурсы (`/tasks`, `/plans`, `/calendar`);
- применяются HTTP-методы (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`);
- отсутствует привязка к `current`, используется явная работа с периодами.

## Базовый URL

```
https://api.smartplanner.com
```

## Аутентификация

Для доступа к API используется JWT Bearer токен.

**Заголовок запроса:**
```
Authorization: Bearer <token>
```

## Основные ресурсы

| Ресурс | Описание |
|--------|----------|
| `/auth` | Авторизация и регистрация |
| `/users` | Данные пользователя |
| `/tasks` | Учебные задачи |
| `/calendar` | События календаря |
| `/plans` | Недельные планы |

## Формат запросов и ответов

**Content-Type:** `application/json`

**Пример ответа успеха:**
```json
{
  "data": {...},
  "meta": {
    "timestamp": "2026-04-20T12:00:00Z"
  }
}
```

**Пример ответа ошибки:**
```json
{
  "code": "VALIDATION_ERROR",
  "message": "Ошибка обработки запроса",
  "details": [...]
}
```

## Коды состояний HTTP

| Код | Описание |
|-----|----------|
| 200 | Успешный запрос |
| 201 | Ресурс создан |
| 204 | Успешно, без содержимого |
| 400 | Ошибка валидации |
| 401 | Неавторизованный доступ |
| 404 | Ресурс не найден |
| 422 | Недостаточно данных |
| 500 | Внутренняя ошибка сервера |
