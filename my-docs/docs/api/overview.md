# Обзор API

API Smart Study Planner построен в стиле REST и соответствует второму уровню зрелости Ричардсона: используются ресурсы, HTTP-методы и статус-коды. Для авторизации применяется Bearer JWT.

## Группы API

| Группа | Назначение |
| --- | --- |
| Auth | Регистрация, вход, выход |
| Users | Профиль и настройки пользователя |
| Tasks | Учебные задачи |
| Calendar | Календарные события |
| Plans | Генерация, получение и сохранение недельного плана |

## Основные сущности

`User` описывает пользователя системы. `Task` является основной единицей учебной работы. `Event` описывает календарные события, которые уменьшают доступное время. `Plan` представляет результат генерации недельного плана. `PlannedTask` фиксирует задачу внутри конкретного плана.

## OpenAPI

Интерактивная спецификация доступна в Docusaurus по маршруту `/api/openapi`.

Файл спецификации: [`/staticopenapi.yaml`](openapi.yaml)

## AsyncAPI

Описание асинхронного взаимодействия находится в разделе [AsyncAPI](./async-api.md). Оно описывает WebSocket-канал для получения статусов генерации плана.
