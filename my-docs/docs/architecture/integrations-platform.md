# LMS-интеграции и платформизация

## Функциональность для замены на платформу

В системе можно заменить ручное создание учебных задач на получение задач и дедлайнов из LMS. В реальной учебной среде задания уже существуют в Moodle, Canvas или внутренней системе вуза.

## Выбранное решение

Используется LMS API. Пользователь подключает LMS через OAuth или токен. После подключения приложение получает список курсов, задания и дедлайны. Эти данные преобразуются в `Task` и `CalendarEvent`.

## Польза интеграции

- снижается объём ручного ввода;
- данные становятся актуальнее;
- продукт легче внедрять в вузах;
- система становится надстройкой над существующей LMS.

## Стратегия платформизации

Smart Study Planner можно продавать как B2B2C-платформу образовательным организациям. Организация оплачивает сервис, а студенты используют его для планирования учебной нагрузки.

## Ценность платформы

Система не заменяет LMS. Она дополняет её за счёт алгоритма планирования, приоритизации задач и распределения нагрузки.
