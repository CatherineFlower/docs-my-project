# Компоненты системы

## Web UI

Клиентская часть отвечает за отображение экранов входа, регистрации, задач, календаря, генерации плана, недельного плана, редактирования и профиля.

## Auth Service

Компонент выполняет регистрацию, авторизацию и завершение сессии. После успешного входа клиент получает JWT-токен.

## Task Service

Компонент управляет учебными задачами пользователя. Он предоставляет получение списка задач, фильтрацию, создание, изменение и удаление задач.

## Calendar Service

Компонент хранит события календаря, которые учитываются при распределении учебной нагрузки. События не являются задачами, но блокируют доступное время.

## Planning Service

Основной доменный компонент. Он объединяет задачи и события, обращается к DMN-модулю для определения приоритета, формирует черновик плана и проверяет перегруз по дням.

## DMN Module

Модуль принимает параметры задачи: срочность, трудоёмкость и наличие дедлайна. На основе таблицы решений он возвращает приоритет `high`, `medium` или `low`.

## Database

Реляционная база данных хранит пользователей, настройки, задачи, календарные события, планы и запланированные задачи.

## Activity Logs

Логи активности используются для аналитики, аудита и анализа поведения пользователя. Они могут храниться отдельно от основной OLTP-модели.
