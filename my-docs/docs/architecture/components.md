# Компоненты системы

## Frontend компоненты

### Экраны приложения

| Экран | Route | Описание |
|-------|-------|----------|
| Вход | `/login` | Авторизация пользователя |
| Регистрация | `/register` | Создание аккаунта |
| Главная | `/home` | Центральная точка входа, задачи на сегодня |
| Задачи | `/tasks` | Список всех задач с фильтрами |
| Календарь | `/calendar` | Просмотр событий календаря |
| Генерация плана | `/generate-plan` | Выбор задач и событий для планирования |
| Недельный план | `/weekly-plan` | Просмотр результата генерации |
| Редактирование плана | `/edit-plan` | Ручное изменение плана |
| Профиль | `/profile` | Управление настройками пользователя |

## Backend сервисы

### Auth Service

Отвечает за аутентификацию и авторизацию пользователей.

**Endpoints:**
- `POST /auth/login` — вход в систему
- `POST /auth/register` — регистрация
- `POST /auth/logout` — выход

### Task Service

Управление учебными задачами пользователей.

**Endpoints:**
- `GET /tasks` — получение списка задач
- `POST /tasks` — создание задачи
- `PUT /tasks/:id` — обновление задачи
- `DELETE /tasks/:id` — удаление задачи

### Plan Service

Генерация и управление недельными планами.

**Endpoints:**
- `POST /plans/generate` — запуск генерации плана
- `GET /plans/weekly` — получение текущего плана
- `PUT /plans/weekly` — сохранение изменений плана

### Calendar Service

Работа с календарными событиями.

**Endpoints:**
- `GET /calendar/events` — получение событий
- `POST /calendar/events` — создание события

## WebSocket сервис

Сервис для асинхронного уведомления о статусе генерации плана.

**Канал:** `/ws/plans/generation-status`

**Статусы:**
- `queued` — запрос в очереди
- `processing` — генерация в процессе
- `completed` — план готов
- `failed` — ошибка генерации
