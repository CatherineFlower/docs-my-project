# Модель данных

## Users

Таблица `users` хранит основную информацию о пользователе: ФИО, email, хеш пароля, университет, даты создания и обновления.

## User Settings

Таблица `user_settings` вынесена отдельно, потому что настройки имеют собственную логику изменения. Она хранит язык, тему интерфейса и включение уведомлений.

## Tasks

Таблица `tasks` хранит учебные задачи пользователя. Поля `due_date`, `estimated_minutes`, `priority` и `status` используются при генерации плана.

## Calendar Events

Таблица `calendar_events` хранит события, которые влияют на доступное время пользователя: пары, встречи, консультации, экзамены.

## Plans

Таблица `plans` хранит недельный план пользователя. Поля `generation_id` и `generation_status` связывают план с асинхронной генерацией.

## Planned Tasks

Таблица `planned_tasks` связывает задачу с конкретным планом. Она содержит дату выполнения, время начала, время окончания, порядок отображения и snapshot-поля.

## Activity Logs

Таблица `activity_logs` хранит события системы и действия пользователя. Поле `payload` хранит дополнительные данные в JSON.
