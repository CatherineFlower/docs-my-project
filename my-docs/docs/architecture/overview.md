# Архитектурный обзор

## Общая архитектура системы

Smart Study Planner построена по архитектуре клиент-сервер с использованием REST API для синхронного взаимодействия и WebSocket для асинхронных уведомлений.

```
┌─────────────┐      ┌──────────────────┐      ┌─────────────────┐
│   Клиент    │◄────►│     Backend      │◄────►│  База данных    │
│   (React)   │ HTTP │     (REST API)   │ SQL  │  (PostgreSQL)   │
└─────────────┘ WS   └──────────────────┘      └─────────────────┘
       ▲                       │
       │                       ▼
       │              ┌─────────────────┐
       └──────────────│   WebSocket     │
                      │     Server      │
                      └─────────────────┘
```

## Компоненты системы

| Компонент | Описание | Технология |
|-----------|----------|------------|
| Frontend | Веб-интерфейс пользователя | React |
| Backend API | RESTful сервис для обработки запросов | Node.js/Python |
| WebSocket Server | Сервер для push-уведомлений о статусе генерации плана | ws/socket.io |
| Database | Хранение данных пользователей, задач, планов | PostgreSQL |
| DMN Engine | Движок для расчёта приоритетов задач | Camunda/собственная реализация |

## Уровни архитектуры

### Уровень 1: Презентационный слой

- Веб-интерфейс на React
- Маршрутизация между экранами
- Состояние приложения (state management)

### Уровень 2: Слой бизнес-логики

- API контроллеры
- Сервисы для работы с задачами и планами
- Алгоритм генерации плана
- DMN-модуль приоритизации

### Уровень 3: Слой доступа к данным

- Репозитории для CRUD операций
- Миграции базы данных
- Транзакционное управление
