# Обзор архитектуры

Smart Study Planner строится как веб-приложение с клиентским интерфейсом, backend API, реляционной базой данных и отдельным контуром логирования.

## Основные компоненты

| Компонент | Назначение |
| --- | --- |
| Web UI | Интерфейс пользователя: задачи, календарь, план, профиль |
| Auth Service | Регистрация, вход, JWT, выход |
| Task Service | CRUD задач и фильтрация |
| Calendar Service | Работа с календарными событиями |
| Planning Service | Генерация недельного плана |
| DMN Module | Определение приоритета задачи |
| Database | Хранение пользователей, задач, событий, планов |
| Activity Log Storage | Хранение логов активности |

## Логика взаимодействия

Пользователь работает с приложением через Web UI. Клиент отправляет запросы к REST API. Для генерации плана backend получает задачи, календарные события и дедлайны, определяет приоритеты, распределяет задачи по дням и сохраняет результат.

## Интеграции

В перспективе система может интегрироваться с LMS вуза и календарём студента. В MVP эти интеграции могут быть заменены ручным вводом или тестовыми данными.
